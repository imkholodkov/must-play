Как идёт запрос: открыть карточку игры

GET /games/292030

1. Роутер app/api/games.py
проверяет, что id — число, иначе 422

2. Сервис app/services/games.py
решает, что делать: игры нет — 404, есть — собрать карточку

3. Репозиторий app/repositories/games.py
SQL-запросы: игра, оценки, цитаты прессы, статус must play

4. Ответ app/schemas/game.py
Pydantic собирает JSON строго по схеме

Каждый слой делает одно дело, поэтому формулы тестируются без БД и HTTP

Связи многие-ко-многим: игры ↔ жанры, теги, категории, языки, разработчики. Схема — docs/erd.md.
