Три контейнера

db — PostgreSQL · app — API и сайт · scheduler — раз в неделю (пн, 03:00) пересчитывает рейтинг и похожие игры по данным, которые уже в базе. Новые данные приходят импортом или через API

Запуск

docker compose up — и миграции применяются сами; данные: одна команда seed или полный импорт

Тяжёлое считается заранее: похожие игры для 30 тыс. игр — около 45 секунд, поэтому не на каждый запрос.
