Что получилось

Веб-сервис, который из сырого датасета Steam делает ответ на вопрос «во что поиграть». В нём пять страниц:

Рейтинг

30 тыс. игр по единому индексу, фильтры по жанру, десятилетию, платформе

Must play

106 игр, которые стоит пройти каждому

Во что поиграть

анкета: жанр, режим, платформа, язык, цена → подборка

Каталог

поиск по 141 тыс. игр; карточка: оценки, цитаты прессы, похожие игры

Аналитика

жанры, годы, строгость изданий, кнопка пересчёта

REST API · 21 эндпоинт

всё то же самое для программ: /games, /rating, /must-play, /recommendations, /analytics, /ml — документация в Swagger

ML-прогноз

через API (Swagger, POST /ml/predict-from-csv) загружаешь CSV с новыми играми — получаешь вероятность хита и высокой оценки прессы

Показать вживую: рейтинг → Witcher 3 → похожие игры → анкета.
