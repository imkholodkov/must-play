Загрузка данных, отчёты и машинное обучение

Загрузка (ETL)

  • Скрипт читает CSV-файлы
  • Чистит и проверяет строки
  • Кладёт в базу данных
  • Повторный запуск не плодит дубли
  • Пишет отчёт: сколько загружено, сколько отброшено и почему

Отчёты

  • Лучшие игры по жанрам и десятилетиям
  • Игры, которые журналисты перехвалили или недооценили
  • Самые строгие и самые щедрые издания

Две ML-модели

  • Станет ли игра хитом — по цене, жанру, платформам
  • Понравится ли игра журналистам — для игр без обзоров
  • Сравниваю 3 алгоритма, оставляю лучший
  • Модель можно загрузить и проверить через API
Метрика выбора модели — ROC-AUC. Эндпоинты: /upload-model, /predict, /predict-from-csv.
