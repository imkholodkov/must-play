## 1. Идея и приоритеты

Must Play — рейтинг игр Steam всех времён, который отвечает на вопрос «во что поиграть».

Приоритеты задал преподаватель:

1. **Задача минимум — очистка и унификация данных** (ETL).
2. **Вторая техническая задача — рекомендательная система.**
3. ML-классификаторы с выбором по ROC-AUC — одобрены дополнительно.

## 2. Принятые решения

| Решение | Почему |
|---|---|
| Проект в одиночку, разработка прямо в main без веток и PR | ревьюеров нет; качество держит CI |
| Без авторизации, личных списков и ролей куратора / администратора | лишний объём, не требуется заданием |
| Must play обновляется сам при пересчёте, без куратора | правило смены статусов остаётся бизнес-логикой |
| Подбор по времени игры не делаем | время игры заполнено только у 8% игр |
| Пороги must play 95 / 93, поправка прессы −7 | подобраны по распределению, см. [ноутбук EDA](../ml/notebooks/eda.ipynb) |
| Модель press с порогом 75, а не 85 | при 85 ROC-AUC падает с 0,740 до 0,622 |
| Датасет на Google Drive, в git только выборка `data/sample/` | GitHub не принимает файлы больше 100 МБ |
| Python 3.12, зависимости в requirements.txt | требование задания |
| Качество рекомендаций — по скрытым тегам с базовыми линиями | жанры входят в признаки, проверка по ним завышена |

## 3. Данные

Датасет Steam: `steam_games.csv` (141 605 игр, 42 поля) и `steam_games_reviews.csv` (цитаты прессы по 13 292 играм). Анализ сырых форматов и распределений — [ml/notebooks/eda.ipynb](../ml/notebooks/eda.ipynb).

| Проблема | Решение в `app/etl/cleaning.py` и `app/etl/reviews.py` |
|---|---|
| владельцы в форматах «0 - 20000» и «0 .. 20,000» | диапазон min / max |
| жанры строками, словарями, теги словарём «тег → голоса» | единый список имён, без дублей и заглушек `#category_…` |
| языки JSON / текст / HTML, в том числе многократно экранированный; названия на других языках | 3 587 → 103 языка, словарь синонимов |
| `metacritic_score = 0` | NULL |
| оценки прессы в /5, /10, /20, /100, % | шкала 0–100 |
| разные написания изданий | общий ключ: 11 152 → 9 246 изданий |
